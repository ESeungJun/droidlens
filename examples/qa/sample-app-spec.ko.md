# DroidLens 샘플 앱 첫 화면 기획서 (QA 예시)

QA 흐름(기획서 → TC 뽑기 → 검토 → 실행 → 결과표)을 처음부터 끝까지 해 보려고 만든 짧은 기획서예요.
대상 앱은 이 저장소의 샘플 앱(`android/sample`, 패키지 `io.github.eseungjun.droidlens.sample`)이고, 아래 기능은 모두 인터넷 없이 확인할 수 있어요.

## 1. 첫 화면

- 1.1 앱을 열면 맨 위 상태 문구가 `SDK <버전> running: true` 로 보인다.
- 1.2 상태 문구 아래에 버튼이 이 순서로 세로로 놓인다: `GET 요청`, `POST 요청`, `폼 POST`, `404 요청`, `로컬 서버 요청`, `스트림 업로드`, `스트리밍 응답`, `DB에 메모 추가`, `PREFS 저장`, `커스텀 이벤트`.

## 2. 메모

- 2.1 `DB에 메모 추가` 를 누르면 메모 하나가 앱 DB 에 저장되고 상태 문구가 `note #<번호>` 로 바뀐다.
- 2.2 다시 누르면 메모가 하나 더 저장되고 번호가 1 커진다.

## 3. 설정

- 3.1 `PREFS 저장` 을 누르면 상태 문구가 `prefs 저장됨` 으로 바뀌고, `settings` 설정에 닉네임 `냥이` 가 저장된다.

## 4. 이벤트

- 4.1 `커스텀 이벤트` 를 누르면 상태 문구가 `이벤트 기록됨` 으로 바뀌고, `button_clicked` 이름의 커스텀 이벤트가 기록된다.

## 5. 로컬 서버

- 5.1 `로컬 서버 요청` 은 8099 번 포트의 시험용 로컬 서버를 부른다. 서버에 닿지 않으면 상태 문구가 `실패:` 로 시작하고 앱은 꺼지지 않는다.
