  participant UI as uiautomator

#빌드·실행·배포

pnpm install          # .githooks 커밋 훅도 설정
pnpm build            # core + mcp
pnpm dev              # 데스크톱 앱 개발 모드 (scrcpy 서버도 받음)
pnpm build:agent      # 에이전트 APK (JDK 17 + Android SDK)
pnpm dist             # 현재 OS용 설치 파일 → apps/desktop/release/
pnpm mcp              # MCP 서버 직접 실행
pnpm typecheck
  • UI 확인: DROIDLENS_OPEN="tab=..&pkg=.." DROIDLENS_SNAPSHOT=<png>로 자체 캡처(프로젝트 메모리). 띄운 개발 빌드는 반드시 끈다.
  • 에이전트를 끄려면 DROIDLENS_AGENT=0.
  • CI(ci.yml): master·develop push와 PR에서 빌드, 에이전트·SDK·샘플 APK, 데스크톱 타입 검사·빌드.
  • 커밋 규칙(commit-convention.yml): push된 커밋과 PR 제목이 Conventional Commits인지 검사.
  • 릴리스(release.yml): v* 태그 푸시 → macOS(서명·공증)·Windows·Linux 빌드 → 설치 파일, zip, blockmap, droidlens-mcp.mjs, 에이전트 APK, SHA256SUMS를 Releases에 올림.
  • 브랜치(git flow, README): develop에서 feature/…(실제로는 feat/…·fix/…) → develop PR, release/<버전> → master, hotfix/<버전> → master, 이후 master를 develop에 병합. 문서만 바꿀 때는 docs/<이름>.
