#DroidLens 결정기록

이 기록은 2026-11-05에 git 히스토리·개발 글에서 복원했다. 근거는 커밋 해시, 개발 글(~/Desktop/claudeProject/dev-post/03-droidlens/post.md, 이하 "개발 글"), 프로젝트 메모리다. 결정은 모두 이승준이 했다.

관련 문서: 기획서 · 설계서 · 구현도 · 로드맵

#2026-10-14 Flipper 대체를 SDK 없이 adb만으로 시작

  • 무엇을 정했나: 기본 기능(뷰 계층·Activity·Fragment·라이브러리)은 모두 adb로 한다. 네트워크·DB·Prefs만 선택형 SDK로 뺀다.
  • 후보: Flipper처럼 SDK 필수 / adb 기본 + SDK 선택.
  • 고른 이유: SDK가 필수면 남의 앱은 못 보고 내 앱도 release 빌드는 못 본다(개발 글 결정표).
  • 누가 정했나: 이승준(개발 글의 목표를 직접 세움).
  • 버린 시도: 없음.
  • 근거: 5dc4369(v0.1.0), 2dd95fa(v0.2.0 SDK).

#2026-10-14 기기 안에 온디바이스 에이전트 APK를 올린다

  • 무엇을 정했나: Instrumentation + UiAutomation을 붙잡고 HTTP로 답하는 13KB 에이전트를 자동 설치한다. 실패하면 uiautomator로 돌아간다.
  • 후보: adb uiautomator dump·dumpsys만 쓰기 / 기기 안 에이전트.
  • 고른 이유: 뷰 계층 1.53초, Activity 확인 17초는 화면을 수십 번 읽는 에이전트에게 너무 길다. 에이전트로 0.03~0.3초, 한글 입력도 된다(개발 글, 591a14e).
  • 누가 정했나: 이승준.
  • 버린 시도: adb만 쓰는 방식(지금은 대체 경로로만 남음).
  • 근거: 591a14e, 개발 글 "2. adb가 너무 느려서".

#2026-10-14 에이전트·SDK는 TCP 대신 유닉스 소켓 + UID 검사

  • 무엇을 정했나: 에이전트를 TCP 127.0.0.1:7912에서 localabstract:droidlens_agent로 옮기고, 접속 UID가 shell·root일 때만 받는다. SDK도 shell·root·앱 자신만 받는다.
  • 후보: TCP 포트 / 유닉스 소켓 + UID 검사.
  • 고른 이유: TCP면 같은 기기의 다른 앱이 UiAutomation 권한(화면 읽기·텍스트 주입)을 빌려 쓸 수 있었다.
  • 누가 정했나: 이승준(보안 리뷰 지적을 반영).
  • 버린 시도: TCP 포트, 에이전트 INTERNET 권한.
  • 근거: f0c4abf, 개발 글 "5. 검증". 이후 소켓을 다른 앱이 먼저 열면 연결하지 않게 보강(71b19d0, 2204ddc).

#2026-10-14 미러링은 scrcpy 서버 + WebCodecs

  • 무엇을 정했나: scrcpy v5 서버를 내려받아 H.264 스트림을 WebCodecs로 디코딩한다. 실패하면 스냅샷 모드로 돌아간다.
  • 후보: 스크린샷 반복(스냅샷 모드) / scrcpy 스트림.
  • 고른 이유: 고프레임(최대 60fps) 미러링.
  • 누가 정했나: 이승준.
  • 버린 시도: 없음(스냅샷 모드는 대체로 남음).
  • 근거: 87cb6a7(v0.3.0). 서버는 SHA256 검증(scripts/fetch-scrcpy.mjs).

#2026-10-14 에이전트가 직접 쓰게 MCP 서버를 내장한다

  • 무엇을 정했나: core 위에 MCP 서버를 두고 Claude Code가 같은 기능을 도구로 쓰게 한다. 앱에 단일 파일 번들을 넣고 설정 탭에서 claude mcp add까지 버튼 하나로 한다.
  • 후보: 기록 없음.
  • 고른 이유: Claude Code로 개발을 거의 다 하니 에이전트가 직접 검증하면 좋겠다고 봤다. Node를 따로 깔지 않아도 되게 Electron 안의 Node로 돌린다(개발 글).
  • 누가 정했나: 이승준(목표 "에이전트가 직접 쓰고 검증").
  • 버린 시도: 없음.
  • 근거: 5dc4369(도구 28개), 7761c1b(43개), 현재 50개.

#2026-10-14 업데이트는 직접 구현한다

  • 후보: 기록 없음.

#2026-10-14 자동 탐색: 누르기 직전에 다시 찾고, 시그니처에서 스크롤 내용 제외

#2026-10-14 SDK 민감 정보는 기기 안에서 가린다

  • 무엇을 정했나: 네트워크 기록을 저장하기 전에 인증 헤더·토큰·비밀번호를 가린다. 키 이름은 부분 일치로, 문자열 안 JSON·GraphQL·multipart·XML까지.
  • 후보: 정확히 같은 키만 / 부분 일치 + 짧은 이름은 정확 일치.
  • 고른 이유: 정확 일치만 하니 newPassword, fcmToken, jwt가 그대로 남았다. 코드 리뷰가 실제로 컴파일해 돌려 보고 찾았다(개발 글).
  • 누가 정했나: 이승준(리뷰 지적 반영).
  • 버린 시도: 정확 일치. 처음 고친 정규식은 ReDoS가 있어 256KB 입력에 60초 넘게 걸렸다 → 되돌아가지 않는 수량자로 19ms 수준(851f231).
  • 근거: 0f6e098, 16905d4, 732abda, 851f231.

#2026-10-14 macOS 임시(ad-hoc) 서명과 한 줄 설치 스크립트

  • 무엇을 정했나: 앱 묶음 전체에 임시 서명을 하고 hardened runtime을 끈다. macOS·Linux용 install.sh로 curl 설치를 제공한다.
  • 후보: 서명 없음 / 임시 서명 / Developer ID.
  • 고른 이유: 서명이 없으면 macOS가 "손상됨"으로 막았다. 임시 서명이면 "그래도 열기"가 된다. curl로 받으면 Gatekeeper 경고 없이 설치된다.
  • 누가 정했나: 이승준.
  • 버린 시도: 서명 없는 빌드.
  • 근거: 39228ea, 0097201. 이후 Developer ID로 바꿈(아래 2026-10-22).
