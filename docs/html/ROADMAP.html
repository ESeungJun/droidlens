#로드맵

#1단계 — adb 코어 + 데스크톱 + MCP (완료, v0.1.0)

  • adb 래퍼, 기기 정보, 입력(탭·스와이프·키·텍스트)
  • 스크린샷, 화면 녹화
  • 뷰 계층 덤프·파싱·셀렉터·압축 텍스트·통계, 3D 깊이 뷰
  • 현재 Activity / Fragment 인식
  • 화면 그래프(구조 시그니처 기반 화면 식별), 수동 기록, 자동 탐색(DFS + 위험 라벨 회피), 최단 경로, mermaid
  • APK 라이브러리 탐지 (DEX type_ids 파싱 + 네이티브 lib + 시그니처 DB)
  • logcat 스트림·크래시
  • 시나리오 기록 + HTML 리포트
  • MCP 서버 28개 도구, 에이전트 2종

#배포 (v0.1.0)

  • electron-builder: macOS arm64/x64, Windows x64/arm64, Linux AppImage
  • MCP 서버 단일 파일 번들을 앱에 내장, 설정·연동 탭에서 원클릭 등록
  • GitHub Actions: CI, 태그 푸시 시 릴리스 자동 빌드

#보안·구조 리뷰 (v0.4.0)

  • 에이전트·SDK 소켓을 adb(shell) 연결만 받도록 UID 검사, 에이전트 TCP 제거
  • Electron sandbox·내비게이션 차단·파일 IPC 경로 제한, 패키지 이름 검증
  • MCP 모듈 분리, 공용 HTTP/포워딩, 폴링 통합·증분 조회

#2단계 — 속도와 깊이

  • 온디바이스 에이전트 APK: 뷰 계층 0.03~0.3초, 접근성 이벤트 기반 Activity 추적, 한글 입력, idle 대기
  • 자동 탐색: CLEAR_TASK 실행, 구조 안정 판정, ANR/크래시 대화상자 처리
  • scrcpy 연동 고프레임 미러링 (v0.3.0, scrcpy v5 서버 + WebCodecs H.264 디코딩, 최대 60fps)
  • scrcpy 컨트롤 소켓으로 입력 지연 단축, 오디오
  • 가상 기기: 이 컴퓨터의 AVD 를 기기 목록에서 골라 실행·종료 (부팅 완료까지 대기 후 자동 선택)
  • 선택형 SDK (v0.2.0, JitPack, debugImplementation + sdk-noop), localabstract 소켓 + adb forward
    • 네트워크 인스펙터 (OkHttp Interceptor): 요청/응답 헤더·본문, 타이밍, 실패
    • DB 브라우저 (SQLite/Room) + SQL, SharedPreferences 조회·편집
    • 커스텀 이벤트
    • 네트워크 목킹: URL·메서드로 맞춘 요청에 응답·연결 실패·지연 (데스크톱 목 규칙, MCP network_mock_*, 스크립트 setup.mocks)
    • DataStore, Compose 트리 상세(recomposition)
  • 자동 탐색 개선: 스크롤 영역 탐색, 입력 폼 더미 값, 로그인 시나리오 프리셋 후 탐색
  • 앱별 화면 지도: 직접 조작·시나리오 실행도 자동 수집, 화면별 눌러 본 버튼 수, 경로 강조·기록된 경로로 화면 이동, 지도 내보내기·가져오기(합치기)
  • 탭 앱 대응: 깊은 곳의 선택 상태(하단 탭)로 탭 화면 구분, 다시 열 때 다른 탭이 떠도 같은 요소·선택된 탭을 실마리로 화면 이동
  • 지정 탐색: 화면에서 고른 버튼·길게 누르기·스와이프만 먼저 실행하고 열린 화면부터 깊이만큼 탐색
  • 화면 그래프 레이아웃: 열은 출발점에서의 단계, 같은 열 안 순서는 dagre로 선이 덜 엇갈리게
  • 그래프 diff (버전 간 화면 변화)

#3단계 — 시나리오 자동화

  • 시나리오 YAML 스크립트 + 러너 (v0.4.0): 셀렉터 대기, optional, 스크롤 탐색, assert 10종(화면·Activity·네트워크·Prefs·DB·이벤트·크래시)
  • 에이전트 검증 중 조작·검사 자동 녹화 → 통과 시 스크립트 저장
  • 회귀 실행: 폴더 일괄 실행 (MCP suite_run, 데스크톱, CLI run — CI용 종료 코드)
  • 결과 대시보드 (실행 이력·성공률 추이), 스크립트 매개변수(계정 등) 주입
  • 스크린샷 비교(시각적 회귀): 스크립트 matchScreenshot, MCP screenshot_compare, 리포트에서 지금 화면을 기준으로 받아들이기
  • 버전 간 비교: 라이브러리 diff, 화면 그래프 diff, REA compare_application_versions 연동
  • 성능: 앱 시작 시간, 프레임(gfxinfo), 메모리(meminfo), CPU 수집 — 데스크톱 성능 탭, MCP perf_startup·perf_stats, 스크립트 startup 단계·perf assert
