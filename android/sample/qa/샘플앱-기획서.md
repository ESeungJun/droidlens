# DroidLens 샘플 앱 첫 화면 기획서 (QA 시험용)

QA 탭(문서 → TC 뽑기 → 검토 → 실행·결과)을 처음부터 끝까지 시험하려고 만든 짧은 기획서다. 대상 앱은 `io.github.eseungjun.droidlens.sample` 이고, 아래 기능은 인터넷 없이 확인할 수 있다.

## 1. 첫 화면

- 1.1 앱을 열면 맨 위에 SDK 상태 문구가 `SDK <버전> running: true` 형식으로 보인다.
- 1.2 상태 문구 아래에 버튼이 세로로 놓인다: GET 요청, POST 요청, 폼 POST, 404 요청, 로컬 서버 요청, 스트림 업로드, 스트리밍 응답, DB에 메모 추가, Prefs 저장, 커스텀 이벤트.

## 2. 메모 저장

- 2.1 "DB에 메모 추가" 를 누르면 메모 하나가 앱 DB 에 저장되고, 상태 문구가 `note #<번호>` 로 바뀐다.
- 2.2 다시 누르면 번호가 1 커진다.

## 3. 설정 저장

- 3.1 "Prefs 저장" 을 누르면 상태 문구가 `prefs 저장됨` 으로 바뀐다.

## 4. 이벤트 기록

- 4.1 "커스텀 이벤트" 를 누르면 상태 문구가 `이벤트 기록됨` 으로 바뀐다.
